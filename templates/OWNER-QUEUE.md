# Owner queue

Decisions a coordinator could not default. The next session reads this first, acts on every answered item, then deletes it. One item per second-level heading: a line starting `Context:` (what the item is and why it is open, enough for a drawdown tutorial), the question, a line starting `Recommendation:` and a line starting `Answer:`. Sessions ask these one at a time ([gated drawdown](../../../skills/campaign-trail/references/drawdown.md)). While any item is open, no session proposes a `/loop`: the RESUME.md banner carries `OWNER-QUEUE not drained: /loop withheld` instead.
